
### Піч

- [ ] Встановлюємо садку.
- [ ] Перевіряємо стан гумового ущільнення та видаляємо з нього сміття і зайві предмети.
- [ ] Закриваємо заслінку печі.
- [ ] Фіксуємо кришку затискачами.
- [ ] Перевіряємо цілісність системи трубопроводів кришки.

### Електрична частина

#### ШУ печі

- [ ]  Вмикаємо автоматичний вимикач печі.
- [ ]  Перемикач джерела керування нагріванням повинен бути в положенні  "MESA"
- [ ]  Вмикаємо автоматичний вимикач "Утилізатор". 
- [ ]  Вмикаємо автоматичний вимикач "Охолоджувач". 
- [ ]  Вмикаємо автоматичний вимикач "Газова шафа".

#### Перевірка роботи вузлів 

- [ ]  Перевіряємо роботу утилізатора: на панелі керування утилізатора повинна спалахнути лампа "Нагрівання". Робоча температура утилізатора: 800 С.
- [ ]  Перевіряємо роботу охолоджувача. На індикаторі повинна показуватися поточна температура рідини на вході/виході, зумер "Аварія" не повинен працювати.
- [ ]  Запускаємо контролер, натиснувши кнопку "Пуск" 

###  Джерела газів

####  Азот

- [ ]  Відкриваємо подачу з джерела (балон, мережа);
- [ ]  Перевіряємо/підлаштовуємо  тиск на  виході з редуктора тиску джерела: 2,5±0,5 атм;
- [ ] Перевіряємо герметичність лінії.

#### Аміак

- [ ]  Зливаємо конденсат з підігрівача аміаку (закріплений на газовому щиті).
- [ ]  Відкриваємо подачу з джерела (балон, мережа);
- [ ]  Перевіряємо/підлаштовуємо  тиск на  виході з редуктора тиску джерела: 2±0,5 атм;
- [ ] Перевіряємо герметичність лінії.

#### Вуглекислота

-  [ ] Вуглекислота. Відкриваємо подачу з джерела (балон, мережа);
-  [ ] Перевіряємо/підлаштовуємо  тиск на  виході з джерела ~ 2±0,5 атм;
-  [ ] Перевіряємо герметичність лінії. 

###  Газова стійка 

####  Азот

-  [ ] Перевіряємо/підлаштовуємо вхідний тиск на манометрі 1,5±0,5 атм. 
-  [ ] Перевіряємо герметичність лінії. Примітка: В цілях безпеки (наприклад у випадку аварійного зникнення живлення) при зупиненій програмі невелика кількість азоту постійно подається в піч.

#### Аміак

-  [ ] Перевіряємо вхідний тиск на манометрі 1,5±0,5 атм.
-  [ ] Перевіряємо герметичність лінії. 

#### Вуглекислота

-  [ ] Перевіряємо/підлаштовуємо вхідний тиск на манометрі 1,5±0,5 атм.
-  [ ] Перевіряємо герметичність лінії. 
-  [ ] Натискаємо кнопку та утримуємо кнопку "Вуглекислота".
-  [ ] Регулювальним вентилем ротаметра налаштовуємо витрату 0,1 м3/год.
-  [ ] Відпускаємо кнопку "Вуглекислота" → подача вуглекислоти повинна припинитися.

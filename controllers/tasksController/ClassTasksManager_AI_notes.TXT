POST /deleteFile, тіло { fName } - deleteTask(fName) - return {err,data:{fName}}
POST /acceptFile, тіло { fName } - setActiveTask(fName) - return Успіх: { err: null, data: { fName } }. Помилка: { err: { ua, en, ru }, data: null }.
POST /getProcessState, тіло {} — data: { acceptedProgram: this.setActiveTask.fileName, programRunning:false }. acceptedProgram має бути назвою зі списку програм.
